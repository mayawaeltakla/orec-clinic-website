# 🦷 Orec Clinic — عيادة أوريك

> عائلتك الطبية في رحلة استعادة ثقتك بابتسامتك وجمالك
> Your family's medical destination for restoring confidence in your smile and beauty — Istanbul, Türkiye

الموقع الرسمي لعيادة أوريك في إسطنبول — موقع تسويقي فاخر متعدد اللغات لخدمات طب الأسنان التجميلي والزراعة.

---

## ✨ المميزات | Features

- 🌍 **10 لغات** — العربية (RTL) والإنجليزية والتركية والألمانية والفرنسية والإسبانية والإيطالية والروسية والبولندية (مع ألمانية سويسرا الموروثة)
- 🎠 **عرض شرائح تلقائي** في الواجهة — صور حقيقية للعيادة تتبدل كل 5 ثوانٍ مع تلاشٍ سلس وأزرار تنقّل تدعم RTL
- 🌗 **الوضع الليلي/النهاري** — ثيم كحلي/ذهبي فاخر قابل للتبديل
- 📞 **روابط اتصال حية** — اتصال مباشر `tel:`، بريد `mailto:`، وواتساب `wa.me` برسالة معبأة مسبقًا
- 📍 **العنوان يفتح خرائط Google** + 7 روابط شبكات اجتماعية
- 📱 **تصميم متجاوب كامل** — سطح مكتب، لوحي، وجوال

## 🛠️ التقنيات | Tech Stack

| الأداة | الغرض |
|---|---|
| [Next.js 16](https://nextjs.org) (App Router) | إطار العمل |
| TypeScript | لغة التطوير |
| Tailwind CSS 4 | التنسيق |
| Lucide Icons | الأيقونات |

## 🚀 التشغيل محليًا | Getting Started

```bash
# تثبيت الحزم
npm install

# خادم التطوير — http://localhost:3000
npm run dev

# نسخة الإنتاج
npm run build && npm start
```

## 📁 هيكل المشروع

```
src/
├── app/                  # صفحات App Router
├── components/clinic/    # مكونات الموقع (هيرو، خدمات، تواصل...)
└── lib/i18n/             # قاموس الترجمة لـ 10 لغات
public/                   # الشعار وصور العيادة الحقيقية
```
